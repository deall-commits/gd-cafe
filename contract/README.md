# GD카페 위탁운영계약서

서울특별시 강남구 삼성로 716, 2층(청담동, 리임빌딩) 소재 **GD카페(GD CAFE)** 의
위탁운영계약서 두 가지입니다. 계약기간만 다르고 나머지 구조는 동일합니다.

| 파일 | 용도 |
| --- | --- |
| `GD카페_위탁운영계약서_1년.docx` | 계약기간 1년 · 서명용 |
| `GD카페_위탁운영계약서_2년.docx` | 계약기간 2년 · 서명용 |
| `GD카페_위탁운영계약서_1년.md` / `_2년.md` | 위 문서의 원본. 조문을 고칠 때는 이 파일을 고칩니다. |
| `build_docx.py` | `.md` → `.docx` 변환 스크립트 |

원본을 고친 뒤 `python3 contract/build_docx.py` 를 실행하면 `.docx` 가 다시 만들어집니다.
(`pip install python-docx` 필요)

## 계약 구조

- **갑 = 위탁자(GD카페)**, **을 = 수탁자(운영자)**
- 을이 자기 명의·자기 계산으로 매장을 운영하고, **매출은 전부 을에게 귀속**합니다.
- 인건비·재료비·소모품비·카드수수료 등 영업비용은 **을이 부담**합니다.
- 그 대가로 **을이 갑에게 매월 금 3,300,000원**(공급가액 3,000,000원 + 부가가치세 300,000원)을 지급합니다.
- **보증금 금 5,000,000원** 을 을이 갑에게 예치합니다.
- 본문 38개 조 + 별지 제1호(시설물 및 집기 인계목록표) 양식.

## 1년형과 2년형의 차이

38개 조 중 30개 조의 문구가 다릅니다. 실질적으로 중요한 차이는 다음과 같습니다.
2년형은 을에게 기간의 안정성을 주는 대신, 갑에게 인상률·중도해지·경업금지 보호를 강화하는 방향으로 설계했습니다.

| 항목 | 1년형 | 2년형 |
| --- | --- | --- |
| 계약기간 (제5조) | 1년 | 2년 |
| 위탁운영비 인상 (제7조) | 기간 중 증액 없음. 갱신 시 협의 | 1차연도 동결. 2차연도에 한하여 **공급가액의 3%** 와 **소비자물가지수 상승률** 중 낮은 금액을 한도로 증액 |
| 보증금 (제8조) | 금 5,000,000원 / 반환기한 30일 | 금 5,000,000원 + 운영비 증액 시 같은 비율로 증액 / 반환기한 45일 |
| 연대보증 최고액 (제8조) | 금 50,000,000원 | 금 70,000,000원 |
| 연체 해지 (제28조) | 2개월 연체 시 최고 후 해지 | 3개월 연체 시 최고 후 해지. 다만 1개월 연체가 4회 이상이면 해소되었더라도 즉시 해지 |
| 무단 휴업 해지 (제28조) | 연속 5일 / 월 통산 7일 | 연속 7일 / 월 통산 10일 |
| 중도해지 (제29조) | 을 위약금 1개월분(예고 미준수 2개월분), 갑 2개월분 | **1년 경과 전 임의 중도해지 불가.** 을 2개월분(예고 미준수 3개월분), 갑 3개월분 |
| 수선 부담 (제14조) | 1건 30만원 이하 을 부담 | 1건 50만원 이하 을 부담 + 「연간 유지보수계획서」 작성 |
| 원상회복 (제31조) | 인계목록표 기재 상태로 회복 | 2년 경과 시 도장·바닥 마감재·좌석 패브릭의 통상 마모는 갑 부담. 훼손 배상액은 잔존가액 한도 |
| 브랜드 개편 (제22조) | 기간 중 전면적 개편 금지 | 60일 전 통지 + 간판·유니폼·포장재 교체비용 분담 |
| 경업금지 (제33조) | 종료 후 6개월 · 반경 500m · 대가 금 3,300,000원 | 종료 후 1년 · 반경 1km · 대가 금 6,600,000원 |
| 불가항력 해지 (제35조) | 연속 30일 또는 통산 45일 | 연속 45일 또는 최근 12개월 통산 90일 |
| 정기 협의 | 없음 | 12개월마다 권장가격·지정 납품처·온라인 채널·브랜드 스탠다드 협의 |

## 검토가 필요한 지점

계약서를 쓰기 전에 짚어야 할 사항입니다. 이 문서는 실무 초안이며, 서명 전 변호사 검토를 권합니다.

1. **상가건물 임대차보호법이 적용될 수 있습니다.** 보증금 5,000,000원 + 월 3,000,000원의
   환산보증금은 3억 500만원으로 서울시 기준(9억원) 이하이고, 을이 2층 카페 부분을 배타적으로
   점유하며 자기 계산으로 영업하는 구조여서 실질이 임대차로 판단될 여지가 있습니다.
   같은 법 제15조는 임차인에게 불리한 약정을 무효로 하므로, 계약서에 갱신요구권·권리금
   회수기회를 포기시키는 문구는 **일부러 넣지 않았습니다**(넣어도 무효이고 분쟁 시 갑에게
   불리하게 쓰입니다). 대신 제4조에서 갑의 관리권 유보, 정기 점검, 공간 일부 점유, POS
   최고관리자 권한 등 위탁운영의 실질을 실제로 갖추도록 정했습니다. **이 조항들은 문서로만
   두지 말고 실제로 이행하고 기록을 남겨야 의미가 있습니다.**
2. **가맹사업법 적용 여부를 확인하십시오.** 영업표지 사용허락 + 경영 통제 + 계속적 대가라는
   요소를 갖추고 있어 가맹사업에 해당할 수 있습니다. 해당한다면 정보공개서를 계약 체결
   14일 전까지 제공해야 합니다(제38조 제6항). 소규모 가맹본부 예외에 해당하는지 먼저 확인하십시오.
3. **영업신고 명의는 을로 합니다**(제11조). 실제 운영자와 신고 명의가 다르면 식품위생법상
   명의대여로 양쪽 모두 처벌 대상이 됩니다.
4. **판매가격은 강제하지 않고 권장가격으로 정했습니다**(제24조). 가격을 강제하면 공정거래법상
   재판매가격유지행위에 해당할 수 있습니다.
5. **갑의 자력구제는 금지됩니다**(제28조 제4항). 해지가 확정되기 전에 출입을 막거나 단전·단수하거나
   시정장치를 바꾸면 형사 문제가 됩니다.
6. **보증금이 담보로 부족합니다.** 5,000,000원은 월 위탁운영비의 약 1.5개월분이어서 연체 +
   원상회복비 + 미결제 납품대금을 함께 감당하지 못합니다. 제8조 제6항의 연대보증인과
   공정증서(또는 이행보증보험)를 반드시 받아 두십시오.
7. **갑이 건물 임차인이라면** 임대인의 위탁운영 서면 승낙을 먼저 받으십시오(제2조 제2항 제3호).
   갑의 임대차가 먼저 끝나면 계약은 그날 종료되고 갑이 을에게 손해를 배상하게 됩니다(제2조 제4항).
